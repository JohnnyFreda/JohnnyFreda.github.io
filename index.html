  • DocBench

    design

    A workbench for benchmarking document-extraction pipelines. Define a dataset, a schema and ground truth, then run positional, LLM-based and hybrid pipelines against them and inspect where each one fails. Evaluation is decoupled from extraction, so stored output can be rescored without paying a provider twice.
