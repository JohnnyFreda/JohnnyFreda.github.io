# User Stories

Grouped by phase (see the roadmap). Format: *As a … I want … so that …*

## Phase 1 — Discovery MVP
- As a fan, I want to set my home location and radius so results are relevant to me.
- As a fan, I want to search for and follow my favorite bands so the app knows my taste.
- As a fan, I want to see upcoming shows by bands I follow near me so I don't miss them.
- As a fan, I want to mark a show as *going* or *interested* so I can track my plans.

## Phase 2 — Recommendations + onboarding
- As a fan, I want nearby shows by bands *similar* to ones I love so I discover new acts.
- As a new user, I want to import my top artists from Spotify so I don't start empty.

## Phase 3 — Alerts
- As a fan, I want a push notification when a followed band announces a nearby show so I
  can grab tickets early.
- As a fan, I want to be alerted about similar-band shows near me so I catch discoveries.
- As a fan, I want to control which alerts and channels I get so I'm not overwhelmed.

## Phase 4 — Social
- As a fan, I want to invite friends via a link so we can coordinate without a friend
  import.
- As a fan, I want to see how many friends are going to a show so I can decide to join.
- As a fan, I want to be notified when a friend is going to a show so we can go together.
- As a fan, I want to control who sees my attendance so I keep my plans private if I want.

## Phase 5 — North star
- As a dedicated/indie fan, I want coverage of small and DIY shows so nothing slips by.
- As a fan, I want recommendations that keep improving so discovery stays fresh.

## The social pillar (Phases 6–8)

Tourify is co-pillar (see [vision.md](vision.md)) — Artists · Venues · Friends.

### Venues & scene (partly built)
- As a fan, I want to follow **venues** so I keep up with the rooms I love, not just bands.
- As a scene regular, I want a venue's upcoming shows **and who I know that follows it** so I
  can plan around a room and my people.
- As a fan, I want "shows at venues I follow / near me" so my **local scene** surfaces.

### Phase 6 — Connections & profiles
- As a fan, I want a profile with my taste, venues, and attendance so others see who I am
  musically.
- As a fan, I want to see mutual friends / bands / venues with someone so a connection feels
  earned.
- As a fan, I want suggested connections from shared bands, venues, and mutuals so I grow my
  scene.
- As a fan, I want to block/report someone so I stay safe (prerequisite for opening social up).

### Phase 7 — Stories & moments
- As a fan at a show, I want to share a short story/moment tied to the event so my connections
  feel the night.
- As a fan, I want to see friends' moments from shows so I feel my scene's energy — and catch
  shows I missed.

### Phase 8 — Messaging
- As a fan, I want to DM a connection so we can coordinate a show.
- As a fan, I want a group chat around an event so everyone going can plan ("who's going /
  where to meet").
